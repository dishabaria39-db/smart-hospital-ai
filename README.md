# Smart Hospital AI

A modern healthcare web application designed to bring multiple hospital and AI-assisted features together in one platform.

The application provides dedicated modules for appointment booking, doctor recommendations, patient prediction, medical report analysis, and an AI chatbot through a responsive React-based interface.

## Features

- **Appointment Booking** – Interface for managing and booking doctor appointments.
- **Doctor Recommendations** – Helps users explore and select suitable doctors.
- **Patient Prediction** – Provides a dedicated interface for patient-related prediction.
- **Medical Report Analysis** – Interface for working with and analyzing medical reports.
- **AI Chatbot** – Interactive chatbot interface for healthcare-related assistance.
- **Dashboard** – Centralized dashboard for accessing application features.
- **User Login** – Login interface for users.
- **Responsive UI** – Designed to provide a clean experience across different screen sizes.

## How to Run Locally
1. Clone the repository
git clone https://github.com/dishabaria39-db/smart-hospital-ai.git
2. Navigate to the project folder
cd smart-hospital-ai
3. Install dependencies
npm install
4. Start the development server
npm run dev
5. Open the application
After running the command, Vite will provide a local URL such as:
http://localhost:5173
Open the URL in your browser.
